A partir du projet du tutoriel OpenclassRoom, qui affiche un lise de synopsisnet images de films,
mettre en place à partir d'un système de listener sur 2 boutons mais en utilisant la meme fonction
générique d'une nouvelle classe 'MoviePage' contenant tous les Movies en champ de constructeur. Les autres
parametres sont deux index: num de page qui est appelle avant de presser sur un boutons quelconque
et num de page qui est rendue apres de presser sur un des deux boutons (prec, suiv)

Note: on utilisera aussi une classe CSS qui rend une opacité de 0 (invisible)

file: main.css
